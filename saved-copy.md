## Why Are We Using AI?

_Tag: USING AI?_

Games can take weeks to build from scratch. And AI is a great tool to learn if used in the right way. So for ArcadeAi, we want to encourage participants to use AI to build the first version of their game, then improve it with their own ideas and creativity. AI helps you learn in this and makes the process a bit faster so you can focus on experimenting, creating, and making something uniquely yours (aka your own first game).

> AI Helps you Build the first version.
> You build the final game.

### AI Helps With

- Creating a prototype
- Writing code
- Fixing bugs
- Adding features
- Explaining concepts

### You Focus On

- Coming up with ideas
- Testing your game
- Improving the design
- Making it fun
- Adding personality

> AI can generate code.
> It can't generate your creativity.

## Choose Your Path: ArcadeAi for Clubs

ArcadeAi is a Hack Club program where you/your members build games and get rewarded. Run it as a workshop at your next meeting—no experience needed, and it works for complete beginners. Clubs are welcome from anywhere in the world!

### 🎁 Club Perks & Grants Profile

Fund your club dynamic! Every approved game submission contributes a solid **$5 GRANT** directly toward your club's custom event ecosystem. Use your collective pile to fund an awesome **Pizza Party**, restock premium **Snacks**, or request custom board games and gear! Specify your group goals directly in the workshop setup form.

[ARCADE GUIDE »](https://www.canva.com/design/DAHLJIkIras/yFGuUKuNm_g_faqWocFEzg/view)

### Running a workshop

Host an ArcadeAi workshop at your club meeting. Members will build their own game using an AI (as per the guide), host it on GitHub Pages, and submit it. Each approved submission earns them rewards. You can use our workshop guide (linked to `#guides` on the old site) to run the session.

### How it works

1. Run the workshop with your club
2. Members build & host their games
3. Close your workshop session
4. Get your collective reward grant!
