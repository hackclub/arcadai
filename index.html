Step 1 · AI allowed

Your AI prompt

This is where your game begins. Use your favourite AI tool to create the first version of your game. Don't worry if it's rough, and it doesn't need to be online yet.

Do this

  1. Pick a classic. Pong, Snake, Breakout, Space Invaders, Flappy Bird, a dodge game. Small games make the best first games.
  2. Write the prompt. Ask for one file, index.html, with the CSS and JavaScript inside it, and ask for comments so you can read the code later. Start from the prompt below.
  3. Run it. Save the code as index.html and open it in your browser. Play it.
  4. Fix it with the AI. Broken? Paste the error message, or describe what's wrong, and ask for a fix. Repeat until it plays.
  5. Track your time. Set up Hackatime before you start so your hours count.

Starter prompt · change the parts in yellow 
Make me a simple arcade game called [GAME NAME] in ONE file, index.html, using only HTML, CSS and plain JavaScript. No libraries, no build tools.

The game: [the player is a spaceship dodging asteroids that fall from the top of the screen].
Controls: arrow keys on desktop, tap or drag on phones.
It needs a start screen, a score, and a game-over screen with a restart button.

Keep the code short and readable, and add comments explaining what each part does so I can edit it myself later.

Any AI tool works: ChatGPT, Claude, Gemini, Copilot, or whatever you already use. Write down which one. You'll need it for the submission.

Step 2 · No AI

Your own edits, no AI

Now it's time to make your game yours. Close the AI tab, open index.html in a code editor, and change things by hand. This is where you add the human touch.

The loop

Find a value›Change it›Save›Refresh›Repeat

Most of a game is numbers and words sitting in plain sight. You don't need to understand every line to change the ones that matter. Three edits, straight from a step-1 game:

- const speed = 3;            // how fast the asteroids fall
+ const speed = 6;            // twice as scary
- ctx.fillStyle = "white";
+ ctx.fillStyle = "#ec3750";  // Hack Club red
- <h1>Asteroid Dodge</h1>
+ <h1>Orpheus: Space Panic</h1>

Not sure what a line does? Read the comment next to it, change it anyway, and see what breaks. If you're really stuck, ask a human in the Slack channel. Not the AI. Not yet.

Upgrade ideas · pick at least five

  • New colours and fonts
  • Rename the game and rewrite every bit of text
  • Tune the speed, gravity, sizes and spawn rate
  • Draw a new character or better art
  • Add a background
  • Improve the UI: start screen, buttons, layout
  • Add a story: who is the player, and why?
  • Make a harder second level by changing values

Step 3 · Your code

Your own features, in JavaScript

Edits change how the game looks. Features change how it plays. Pick one or two from the list, or invent your own, and write the JavaScript yourself. You can ask an AI to explain a concept, but the code that goes in is yours.

Example · a high score that survives a refresh

About ten lines, and your game suddenly has a reason to play again.

// Load the best score (or 0 the first time)
let best = Number(localStorage.getItem("best")) || 0;

function gameOver() {
  if (score > best) {
    best = score;
    localStorage.setItem("best", best);  // remember it
  }
  showGameOverScreen(score, best);
}

Every feature has the same shape: keep track of something (a variable), change it when something happens (an event), and show it (draw it). That's most of game programming.

Your ideas, your code.

Feature ideas

  • High score saved with localStorage
  • A power-up: shield, slow motion, double points
  • Difficulty that ramps up over time
  • Lives, or a health bar
  • Sound effects with the Audio API
  • A second enemy with its own movement
  • Pause with the P key
  • A combo multiplier
  • Levels, or a boss

Final · Ship it

Put it online and submit

Time to ship your game. Publish it online, share what you've built, and get rewarded.

GitHub Pages in four moves

  1. Create a public repository on GitHub and upload index.html, plus any images or sounds.
  2. Open Settings → Pages, choose the main branch, and save.
  3. Wait a minute. Your game is live at username.github.io/repo-name.
  4. Open it on your phone and play it once. If it works there, it works.

ArcadAI for Clubs

Using AI?

Why are we using AI?

Games can take weeks to build from scratch. And AI is a great tool to learn if used in the right way. So for ArcadAI, we want to encourage participants to use AI to build the first version of their game, then improve it with their own ideas and creativity. AI helps you learn in this and makes the process a bit faster so you can focus on experimenting, creating, and making something uniquely yours (aka your own first game).

AI helps you build the first version.
You build the final game.

AI helps with

  • Creating a prototype
  • Writing code
  • Fixing bugs
  • Adding features
  • Explaining concepts

You focus on

  • Coming up with ideas
  • Testing your game
  • Improving the design
  • Making it fun
  • Adding personality

AI can generate code.
It can't generate your creativity.

FAQ

Questions, answered.

Do I need to be in a club?

Yes. ArcadAI runs as a workshop at Hack Club meetings, and games are handed in through the workshop. Not in a club yet? You can start one at clubs.hackclub.com.

Do I need to know how to code?

No. Step 1 needs zero code: the AI writes it. Steps 2 and 3 teach you by changing code that already works, which is the fastest way to learn.

Which AI tool should I use?

Whatever you already have. ChatGPT, Claude, Gemini and Copilot all work. Write down which one you used. It's part of your step-1 submission.

Why HTML, CSS and JavaScript?

Because you can read every line, change it with any text editor, and put it online for free on GitHub Pages. No engine to install, no licence, nothing to export.

How long does it take?

A club workshop gets most people through step 1 in a single session. Steps 2 and 3 are yours to pace. Keep Hackatime running the whole time so your hours count.

I'm stuck.

Ask in #arcade-ysws on the Hack Club Slack. Someone there has hit the same bug.
