Build your first game with AI. Then make it yours.

ArcadAI is a three-step program for making a retro arcade game in plain HTML, CSS and JavaScript. An AI writes the first version. You do everything after that. Ship it and get rewarded.

How it works

Three steps from a prompt to a playable game.

Each step has one job. The AI's role shrinks as you go: it writes the first version, then it's your turn.

1

Your AI prompt

Describe the game you want and let an AI tool write the first version. The goal is a playable prototype. Rough is fine.

AI writes the code
2

Your own edits, no AI

Close the AI tab, open the code and change it by hand: colours, speed, text, art, a new character. At least five improvements. This is where you make it yours.

AI switched off
3

Your own features, in JavaScript

Write new code that changes how the game plays: a power-up, a high score, levels, sound. Your ideas, your code.

AI explains, you write

Then ship it

Put the game on GitHub Pages, hand in the link at your club's workshop, and get rewarded.

Using AI?

Why are we using AI?

Games can take weeks to build from scratch. And AI is a great tool to learn if used in the right way. So for ArcadAI, we want to encourage participants to use AI to build the first version of their game, then improve it with their own ideas and creativity. AI helps you learn in this and makes the process a bit faster so you can focus on experimenting, creating, and making something uniquely yours (aka your own first game).

AI helps you build the first version.
You build the final game.

AI helps with

  • Creating a prototype
  • Writing code
  • Fixing bugs
  • Adding features
  • Explaining concepts

You focus on

  • Coming up with ideas
  • Testing your game
  • Improving the design
  • Making it fun
  • Adding personality

AI can generate code.
It can't generate your creativity.

FAQ

Questions, answered.

Do I need to be in a club?

Yes. ArcadAI runs as a workshop at Hack Club meetings, and games are handed in through the workshop. Not in a club yet? You can start one at clubs.hackclub.com.

Do I need to know how to code?

No. Step 1 needs zero code: the AI writes it. Steps 2 and 3 teach you by changing code that already works, which is the fastest way to learn.

Which AI tool should I use?

Whatever you already have. ChatGPT, Claude, Gemini and Copilot all work. Make a note of which one you used.

Why HTML, CSS and JavaScript?

Because you can read every line, change it with any text editor, and put it online for free on GitHub Pages. No engine to install, no licence, nothing to export.

How long does it take?

A club workshop gets most people through step 1 in a single session. Steps 2 and 3 are yours to pace.
